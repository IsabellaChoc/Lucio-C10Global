Interactive Decision Lab

Explore decision-making under uncertainty. Edit alternatives, states of nature, payoff values and probabilities. Compare four decision criteria and follow every stage of the elimination process.

1. Preloaded decision problems

Choose an example to load its alternatives, states of nature, payoff matrix and probabilities. You can modify every value after loading it.

2. Edit the decision model

Payoffs are numerical outcomes; higher values are better. Enter probabilities as decimals: 0.30 means 30%. Probabilities must be between 0 and 1 and add up to exactly 1 (100%).

3. Decision criteria and comparison

The cards summarize the best result for each criterion. The comparison table shows the calculated value for every alternative, including ties. Minimax Regret uses the maximum regret for each alternative, then selects the smallest one.

4. Staged filtering

The filtering order is Maximax → Maximin → Minimax Regret → EMV/Bayes. At each stage, only alternatives tied for the best criterion value among the alternatives still remaining advance. Removed alternatives are shown at every step.

This diagram shows the number of alternatives entering and leaving each stage, plus the final outcome. It updates with the model.
